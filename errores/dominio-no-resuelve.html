Errores web explicados

El dominio no resuelve: para internet, la web no existe

El DNS no devuelve ninguna dirección para el dominio, así que nadie puede llegar a la web: el navegador muestra DNS_PROBE_FINISHED_NXDOMAIN o «No se puede acceder a este sitio». Si el dominio caducó, también deja de funcionar su correo.

Causas más habituales

  • El dominio caducó y no se renovó: es la causa más grave y una de las más frecuentes.
  • Se borró o se editó mal un registro DNS (A, AAAA o CNAME).
  • Se cambiaron los nameservers (por ejemplo, al pasar a Cloudflare) sin copiar todos los registros.
  • El registrador suspendió el dominio porque el titular no verificó su email.
  • El dominio apunta a una dirección privada o interna.

Qué revisar primero

  1. Revisa en el registrador la fecha de caducidad del dominio y si está suspendido.
  2. Comprueba qué nameservers tiene configurados el dominio.
  3. Revisa los registros A o CNAME del dominio y del www.
  4. Busca en el email del titular avisos del registrador pendientes de verificar.
