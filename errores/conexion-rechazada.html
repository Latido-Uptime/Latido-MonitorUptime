Errores web explicados

Conexión rechazada: el servidor no acepta conexiones

La dirección del servidor responde, pero nadie acepta la conexión en el puerto de la web: el 80 para http o el 443 para https. Normalmente el servidor web no está en marcha o un firewall rechaza la conexión. El navegador lo muestra como ERR_CONNECTION_REFUSED.

Causas más habituales

  • El servidor web (Nginx, Apache) está parado o no arrancó tras un reinicio.
  • Un error en su configuración le impide arrancar.
  • Un firewall bloquea los puertos 80 o 443.
  • El DNS apunta a la IP de un servidor antiguo que ya no aloja la web.
  • El servidor cortó la conexión a medias por un fallo o un reinicio.

Qué revisar primero

  1. Comprueba que el servidor web está en marcha y revisa sus registros de arranque.
  2. Revisa el firewall del servidor y el del proveedor: los puertos 80 y 443 deben estar abiertos.
  3. Confirma que la IP del DNS es la del servidor actual.
